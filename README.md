[下载搞研究 V1.3 安装包](./1.3.0-20260819.dmg)

## 为什么做它

做科研久了，最容易失控的往往不是实验，而是：这篇稿件到哪一步了、那项成果我是第几作者、项目哪个节点快超期、实验数据放在哪个文件夹、周报和汇报 PPT 去哪里找、这个月哪笔补助应该到账……

所以我做了「搞研究」，希望少开几个表格、少翻几个文件夹，把时间真正留给研究本身。

## 主要功能

### 在投管理

- 在内置页面登录常见投稿系统并导入论文，也支持小众系统的手动录入。
- 记录投稿状态、状态历史、稿号、投稿网址和备注。
- 自动统计当前投稿状态分布，并显示持续天数、关注和超期提醒。
- 支持上下拖动记录，自定义排列顺序。

### 成果管理

- 管理期刊论文、会议论文、毕业论文、专著、专利、数据集和软件等成果。
- 统计成果类别、本人署名顺序和年度增长趋势；署名支持通讯作者。
- 期刊论文可查询 SCIE、SSCI、ESCI、EI、A&HCI、中文核心、CSSCI、CSCD、中科院 2025 分区、影响因子和 JCR 分区等信息。
- 专利可细分为发明专利、实用新型和外观设计。
- 支持上传 PDF 和图片附件，并可上下拖动记录排序。

### 项目管理

- 自定义项目内容、具体步骤和时间节点。
- 为每个步骤设置开始日期、结束日期和完成状态。
- 自动生成甘特图，并区分已完成、已逾期、进行中和未开始任务。

### 实验数据、总结报告与重要文献

- 三个模块均采用“文件夹—文件列表”两层结构，数据彼此隔离。
- 可自由创建和重命名文件夹，按项目或主题整理文件。
- 支持 Word、Excel、PPT、PDF、Markdown、TXT、图片、压缩包等常见格式。
- 文件可修改显示名称、添加自定义标签，并按上传时间或标签排序筛选。
- “重要文献”定位为轻量收藏，只建议保存真正重要的参考文献。

### 证书管理

- 以多维表格管理证书名称、时间、标签和附件。
- 内置竞赛、文体、任职等常用标签，也可以创建自定义标签。
- 支持上传 PDF 和图片附件。

### 资金管理

- 管理工资、补助、奖金和项目经费等不同资金项目。
- 为每项资金设置金额、适用年份、实际发放月份和收款账户。
- 自动汇总上个月、本月和下个月的预计到账金额。

## 安装方法

1. 下载 `1.3.0-20260819.dmg`。
2. 打开 DMG，将「搞研究」拖入“应用程序”文件夹。
3. 从“应用程序”中启动「搞研究」。

当前安装包使用本地签名，尚未完成 Apple 公证。如果 macOS 首次启动时提示无法验证开发者，请在“系统设置 → 隐私与安全”中确认仍要打开。

## 从旧版本迁移到 V1.3

### 同一台 Mac 升级

1. 完全退出旧版本「搞研究」。
2. **不要删除** `~/Library/Application Support/AcademicAchievementManager` 文件夹。
3. 打开 V1.3 的 DMG，把「搞研究」拖入“应用程序”；系统询问时选择“替换”。
4. 第一次启动 V1.3。应用会自动读取旧资料库并升级数据结构，在投记录、成果、项目、证书、资金和全部附件都会继续保留。
5. 进入各模块核对记录数量和附件能否正常打开，确认无误后再删除旧安装包。

### 迁移到另一台 Mac

1. 在旧 Mac 上完全退出「搞研究」。
2. 在访达中按 `Shift + Command + G`，前往 `~/Library/Application Support/`。
3. 将整个 `AcademicAchievementManager` 文件夹复制到新 Mac 的同一路径。**不能只复制 `library.json`**，否则成果、证书、实验数据、总结报告和重要文献的附件不会一起迁移。
4. 在新 Mac 上安装并首次启动 V1.3，应用会自动完成数据结构升级。

自动迁移前，应用会把旧资料库及附件复制到：

```text
~/Library/Application Support/AcademicAchievementManager-MigrationBackups
```

投稿系统登录会话由 macOS WebKit 单独保存，换 Mac 后通常需要重新登录；EasyScholar Secret Key 保存在原 Mac 的钥匙串中，换 Mac 后也需要重新填写。

## 数据说明

- 软件不要求额外注册账号，资料保存在用户自己的 Mac 上。
- 主资料库位于 `~/Library/Application Support/AcademicAchievementManager/library.json`。
- 成果、证书和资料文件的副本保存在同一目录下的附件文件夹中。
- 建议定期使用软件内的备份功能，并另外备份整个 `AcademicAchievementManager` 文件夹。
