# 搞研究

搞研究是一个无需注册账号的 macOS 学术成果管理应用。它包含“在投管理”“成果管理”“项目管理”“实验数据”“总结报告”“重要文献”“证书管理”和“资金管理”八个模块：在投论文可从投稿系统自动导入，也可手动建立并更新状态；成果与证书记录可手动管理并保管附件；项目可自定义内容、步骤和时间节点；实验数据、总结报告与重要文献采用两层文件夹结构；资金可按年度、月份及收款账户管理。

当前版本：**V2.1**

## 下载与安装

- 当前版本：**V2.1（2026 年 8 月 20 日）**
- 安装包：[下载搞研究 V2.1](./2.1.0-20260820.dmg)
- 系统要求：macOS 13.0 或更高版本，支持 Apple 芯片和 Intel Mac。

安装步骤：

1. 下载并打开 `2.1.0-20260820.dmg`。
2. 将“搞研究”拖入“应用程序”文件夹；升级时选择“替换”。
3. 从“应用程序”中启动“搞研究”。

当前安装包使用本地签名，尚未完成 Apple 公证。如果 macOS 首次打开时提示无法验证开发者，请在“系统设置 → 隐私与安全”中选择仍要打开。

## 当前功能

- 原生 macOS 界面，无额外账号、无后端、无分析服务。
- 设置中可选择浅色、深色或跟随系统外观；默认使用浅色。
- 设置中可随时切换简体中文与英文，界面偏好独立保存，不修改用户记录或附件。
- 支持导出和恢复 `.gaoyanjiu` 完整备份包，备份同时包含全部记录、成果附件、证书附件、实验数据、总结报告、重要文献及回收站内容。
- 每天首次启动时自动创建一份完整备份，默认滚动保留最近 7 份；恢复前还会额外创建安全副本。
- 八个模块的记录、文件夹、文件及附件删除后先进入回收站，保留 30 天，支持立即撤销、逐项恢复、彻底删除和清空回收站。
- 可选开启 macOS 系统通知，自定义投稿状态持续天数和项目节点提前提醒天数；提醒只在本机生成。
- PDF、Office、文本和图片等常见附件支持应用内 Quick Look 快速预览。
- 实验数据、总结报告和重要文献支持文件正文检索；PDF、Markdown、TXT 以及 DOCX、XLSX、PPTX 可直接建立全文索引，其他格式使用系统元数据提取。
- 设置中可从公开 GitHub 仓库检查新版本并打开下载安装地址，不上传任何用户数据。
- 八个并列管理模块：在投管理、成果管理、项目管理、实验数据、总结报告、重要文献、证书管理和资金管理。
- 在投论文可手动添加，支持自定义状态、状态起始日期、稿号、网址和备注，变更状态时自动留存历史。
- 在投管理和成果管理中的记录支持上下拖动排序，并持久保存自定义顺序。
- Editorial Manager 导入仅接受包含真实稿号、标题和状态的稿件行，登录页、按钮标签和页面文件名不会再被当作论文；已知门户会优先显示真实期刊名。
- 成果管理支持期刊论文、会议论文、毕业论文、专著、专利、数据集、软件等类型，可添加多个 PDF 或图片附件，并记录本人署名顺序。
- 新建期刊成果时会根据输入内容联想相近期刊；选择刊名后自动填写 ISSN，并通过 EasyScholar 匹配收录、分区和影响指标。
- 成果管理自动显示成果类别数量图，以及一作、通讯作者和其他署名顺序的分布图。
- 成果类别图会分别统计发明专利、实用新型和外观设计，不再合并为一个“专利”类别。
- 在投管理自动显示当前投稿状态分布，以及各论文在当前状态的持续天数；60–89 天标为关注，满 90 天标为超期，终态稿件不提醒。
- 成果管理自动显示按完成或发表年份统计的成果增长趋势图。
- 项目管理支持自定义项目内容，任意添加或删除具体步骤，并为每个步骤设置说明、开始日期、结束日期和完成状态。
- 项目甘特图自动汇总所有步骤，以不同颜色标记已完成、已逾期、进行中和未开始。
- 甘特图日期范围会在两端自动留白，最后一个时间标签不会被界面边缘截断。
- 实验数据、总结报告和重要文献均采用“文件夹—文件列表”两层结构，三个模块的数据彼此隔离。
- 文件夹按吸附网格自动排列，支持拖动改变顺序，并持久保存各模块自己的排列；也支持创建、重命名和删除。
- 文件支持批量上传、打开、在访达中显示、修改显示名称、自定义标签和删除。
- 支持 Word、Excel、PPT、PDF、Markdown、TXT、RTF、CSV、图片、压缩包等常见资料格式；文件列表默认按上传时间排列，也可按自定义标签排序和筛选。
- 重要文献模块会提示用户保持轻量使用，仅保存真正重要的参考文献。
- 证书管理采用原生多维表格，至少包含名称、时间、标签和附件四列；支持竞赛、文体、任职等快捷标签以及任意自定义标签。
- 证书表格可点击时间列或标签列排序；不同标签使用稳定且彼此区分的颜色。
- 每条证书记录可上传多个 PDF 或图片附件，并支持查看、继续添加和删除。
- 资金管理采用原生表格，包含资金名称、金额、适用年份、发放周期和收款账户；每项资金可独立勾选 1–12 月的实际发放月份。
- 资金表格上方自动汇总上个月、本月和下个月的预计到账总额及资金项数，跨年月份也会按适用年份正确计算。
- 期刊论文可通过 EasyScholar 自动检索 SCIE、SSCI、ESCI、EI、A&HCI、JCR 分区、2025 中科院分区、IF、北大核心、CSSCI、CSCD、中国科技核心等信息。
- EasyScholar Secret Key 仅保存在 macOS 钥匙串，不写入成果数据或备份文件。
- 专利可细分为发明专利、实用新型和外观设计。
- 应用内出版商登录与自动导入；登录 Cookie 由系统 WebKit 保存在本机。
- 投稿门户账号密码可由用户主动保存到 macOS 钥匙串，之后在内置浏览器中一键填写并登录；密码不会进入应用资料库或完整备份。
- 投稿门户使用现代 Safari 兼容标识，并在当前窗口承接登录弹窗和新窗口链接，兼容 Editorial Manager 等仍采用旧式浏览器检测的网站。
- Editorial Manager 支持 `default2.aspx` 的标准表格、ARIA 网格和响应式带标签行，可读取稿号、标题、初始投稿日期、状态日期与当前状态。
- 支持 Springer Nature、ScholarOne、Taylor & Francis、Wiley、IEEE、ACS、OpenReview、Editorial Manager、MDPI、Nature Portfolio、AIP 和 Frontiers。
- 也支持 Editorial Express、Copernicus Office、eJournalPress、HighWire BenchPress、Manuscript Manager、Scholastica、Kriyadocs、OJS 和 Janeway。
- 对没有统一作者首页的平台，会先要求输入期刊专属投稿网址；仍支持任意自定义投稿网站。
- 本地状态历史、更新标记、搜索、归档、回收站和完整备份恢复。
- 已登录门户的“一键刷新全部”。

本地资料库位于：

```text
~/Library/Application Support/AcademicAchievementManager/library.json
```

成果附件的副本位于同一目录下的 `Attachments` 文件夹。

证书附件的副本位于同一目录下的 `CertificateAttachments` 文件夹。

实验数据、总结报告和重要文献的文件副本位于同一目录下的 `ManagedDocuments` 文件夹。

出版商密码不会写入此文件。网页会话数据由 WebKit 单独管理；用户主动保存的一键登录信息由 macOS 钥匙串加密保管。

## 从旧版本迁移到 V2.1

同一台 Mac 升级时，不需要手动导出或重新导入数据：

1. 完全退出旧版本“搞研究”。
2. 不要删除 `~/Library/Application Support/AcademicAchievementManager` 文件夹。
3. 打开 V2.1 的 DMG，把“搞研究”拖入“应用程序”；系统询问时选择“替换”。
4. 第一次启动 V2.1。应用会自动读取 V2.0 及更早版本的资料库并升级数据结构，在投记录、成果、项目、证书、资金、资料文件夹和全部附件都会继续保留；KSAS 的旧 Editorial Manager 占位刊名会自动修正。
5. 进入各模块核对记录数量和附件能否正常打开，确认无误后再删除旧安装包。

迁移到另一台 Mac 时，需要复制完整资料目录，不能只复制 `library.json`：

1. 在旧 Mac 上完全退出“搞研究”。
2. 在访达中按 `Shift + Command + G`，前往 `~/Library/Application Support/`。
3. 将整个 `AcademicAchievementManager` 文件夹复制到新 Mac 的同一路径；其中包含资料库以及 `Attachments`、`CertificateAttachments`、`ManagedDocuments` 等附件目录。
4. 在新 Mac 上安装并首次启动 V2.1，应用会自动完成数据结构升级。

V2.1 也可以直接使用工具栏中的“备份与恢复”：旧 Mac 导出一个 `.gaoyanjiu` 文件，在新 Mac 安装 V2.1 后选择“从完整备份恢复”即可，不需要手动寻找资料目录。

自动迁移前，应用会把旧资料库及附件复制到：

```text
~/Library/Application Support/AcademicAchievementManager-MigrationBackups
```

网页投稿系统的登录会话由 macOS WebKit 单独保存；一键登录信息和 EasyScholar Secret Key 保存在原 Mac 的钥匙串中，不包含在 `.gaoyanjiu` 备份内，换 Mac 后需要重新填写。

## 导入说明

1. 在“在投管理”中点击“添加在投”，选择“从投稿系统导入”。
2. 在内置网页中登录出版商账号并进入稿件列表。
3. 系统会自动尝试导入；也可以点击“立即导入”。
4. ScholarOne、Editorial Manager 和 OJS 常常要求期刊专属网址，可直接粘贴到导入窗口地址栏。

有些第三方单点登录服务可能拒绝嵌入式登录窗口。遇到这种情况，请优先使用出版商自己的账号/密码登录入口；这不会影响已经建立的本地会话。
