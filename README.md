<h1 align="center">搞研究</h1>

<p align="center">
  把投稿网站、成果表格、项目甘特图、证书文件夹和资金记录，装进一个 macOS App。
</p>

## 下载

当前版本：**0.9.0**（2026 年 8 月 18 日）

[下载搞研究 0.9.0 安装包](./0.9.0-20260818.dmg)

系统要求：macOS 13.0 或更高版本，支持 Apple 芯片和 Intel Mac。

## 为什么做它

做科研久了，最容易失控的往往不是实验，而是：这篇稿件到哪一步了、那项成果我是第几作者、项目哪个节点快超期、证书 PDF 放哪了、这个月哪笔补助应该到账……

所以我做了「搞研究」，希望少开几个表格、少翻几个文件夹，把时间真正留给研究本身。

## 主要功能

### 在投管理

- 在内置页面登录常见投稿系统并导入论文。
- 支持小众会议、期刊和自建系统的手动录入。
- 自动统计当前投稿状态分布。
- 记录论文处于当前状态的持续天数，并显示关注与超期提醒。
- 保存投稿状态历史、稿号、投稿网址和备注。

### 成果管理

- 管理期刊论文、会议论文、专著、专利、数据集和软件成果。
- 统计各类成果数量、本人署名顺序和年度增长趋势。
- 期刊论文可查询 SCIE、SSCI、ESCI、EI、A&HCI、中文核心、CSSCI、CSCD、中科院 2025 分区、影响因子和 JCR 分区等信息。
- 专利可细分为发明专利、实用新型和外观设计。
- 支持为成果上传 PDF 和图片附件。

### 项目管理

- 自定义项目内容、具体步骤和时间节点。
- 为每个步骤设置开始日期、结束日期和完成状态。
- 自动生成甘特图，并区分已完成、已逾期、进行中和未开始任务。

### 证书管理

- 以多维表格管理证书名称、时间、标签和附件。
- 内置竞赛、文体、任职等常用标签，也可以创建自定义标签。
- 支持上传 PDF 和图片附件。

### 资金管理

- 管理工资、补助、奖金和项目经费等不同资金项目。
- 为每项资金设置金额、适用年份、实际发放月份和收款账户。
- 自动汇总上个月、本月和下个月的预计到账金额。

## 安装方法

1. 下载 `0.9.0-20260818.dmg`。
2. 打开 DMG，将「搞研究」拖入“应用程序”文件夹。
3. 从“应用程序”中启动「搞研究」。

当前安装包尚未完成 Apple 公证。如果 macOS 首次启动时提示无法验证开发者，请在“系统设置 → 隐私与安全”中确认仍要打开。

## 使用说明

- 软件不要求额外注册账号，论文和成果由用户自行导入或创建。
- 投稿系统的登录过程在应用内置网页中完成。
- 建议定期使用软件内的备份功能导出资料库。
